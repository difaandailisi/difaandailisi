## 一、瞬间重构 · 纸世界

> AI 直接生成一件你此刻要用的东西——说不清是菜单还是 APP——
> 用完立即销毁，**但数据保持连续**。

听起来像科幻。但拆开看，它是三个可以单独检验的命题：

- **P1 界面不是资产** — 界面 = f(状态, 意图)，随用随算，不必预先存在
- **P2 生命周期短于产品周期** — 生成物寿命 = 本次使用时长，而非软件版本周期
- **P3 状态与界面彻底解耦** — 丢弃界面不损失任何信息

六年后，2026 年的前沿技术在四个不同层上做了同一个动作，各拆开了一样东西：
DeepSeek Harness 拆开**组件生命周期**，Engram 拆开**记忆与推理**，
OpenAI Apps SDK 拆开**界面与 APP**，Anthropic Skills 拆开**规则与常驻提示**。

而 **「界面本身由生成器决定」这一格，仍然空着**。这个仓库指向的就是那一格。

仓库里有一份 2023 年的原文（逐字保留）、一份系统化整理、一份类比随笔，
以及一份早期推演。**建议先读整理的第三部分**——先知道边界，才不会被原文里的
电子纸硬件设想带跑。

文字部分 **CC0**：可以复制、修改、商用、闭源再发布，**连署名都不需要**。

## 三、NFCSHARE 荣耀版

Windows 桌面工具，为华为/荣耀设备生成「一碰传」NFC 标签。

标签载荷格式很朴素：

```
SN=<16位，空格转 A 补齐>|MAC=<12位大写>|MODELID=<8位>
```

电脑固定 `MODELID=00000506`，平板/手机查型号表。工具做的事就是：连设备取 SN 和
蓝牙 MAC，归一化，拼成字符串，生成二维码，手机扫码后写入 NFC 贴纸。

在华为原版基础上重写的是**取数逻辑**：12 条蓝牙 MAC 候选路径（含 Android 15+ 专用，
以及荣耀私有的 `vendor.hardware.bt.mac` / `vendor.honor.bt.mac`）、
型号与设备名双重匹配、剥离柔光版/Lite/Pro/Max/SE 等后缀。

MIT 许可。

## 四、V100 跑达芬奇不黑屏

一块 Tesla V100 计算卡配一张亮机卡，在 Windows 上打开 DaVinci Resolve——
界面能出来，监视器全黑，按播放更黑。这不是软件坏了，是三个设定撞在一起：

- **V100 没有显示输出**，Windows 下只跑 TCC 模式，不进 WDDM 图形栈，**只能算不能画**
- **达芬奇的界面是 OpenGL 画的**，启动时必须找一块正在承担显示输出的 GPU 建上下文
- 界面建在亮机卡、CUDA 解码指向 V100，两块卡不是同一设备，达芬奇**直接给黑屏，不降级**

说白了：**OpenGL 上下文建在 A 卡，CUDA 落在 B 卡，而它要求两者是同一块卡。**

仓库把三条视频里的三种解法拆成了逐步清单，每条都标了时间戳、旁白原话，配逐帧放大的截图：

| 方案 | 亮机卡 | 做法 | 步骤 |
|---|---|---|---|
| 一 | 任意 | 改 OpenGL ICD 注册表，强制走 NVIDIA 驱动 | 8 |
| 二 | NVIDIA | 显示卡设默认 GPU + 达芬奇偏好里取消「自动」 | 3 |
| 三 | AMD | 网易 UU 虚拟屏顶掉物理屏，让 V100 成为唯一可见设备 | 14 |

技术上最值得说的一点：三种方法看着完全不同，落点其实是同一句话——
**让 OpenGL 上下文和 CUDA 处理落在同一块卡上，而这卡是 V100**。
改系统、改应用层、改显示环境，只是“骗”的层级不同。

> **这份不是我发明的方案。** 原作者是 B 站 UP 主「水芙的达芬奇」，
> 三条视频的链接、BibTeX 引用都放在仓库里。我只做结构化整理、逐帧核对，
> 以及把“为什么黑”讲清楚——顺带标出了视频与文案本身不一致的 5 处。

## 关于第三方组件与使用风险

这部分我写得很直白，因为含糊对谁都没好处。

**ADB（`NFCSHARE-Honor-Edition/adb/`）**
`adb` 是 Google / Android Open Source Project 的官方工具，**不是本项目写的**，
版权归其作者所有。本项目只是随附一份，方便没有装 Android SDK 的人直接用。
依据是 **Apache-2.0** 明确允许再分发，条件是保留 `NOTICE.txt`。
目录内 `README.md` 附了三个文件的 SHA-256，可自行校验，也可完全不用它、
改去 [platform-tools 官方页](https://developer.android.com/tools/releases/platform-tools) 下载。

**一碰传助手（`com.huawei.touchshare` / `com.hihonor.touchshare`）**
本仓库**不提供下载**。原因是它并非通用应用——它调用华为/荣耀设备侧的私有服务，
装到其它品牌手机上跑不起来，所以官方不面向所有人分发；市面上流传的多是
从设备提取的改版，甚至破解版，来源不可验证、完整性无法校验。

正规获取路径：系统自带 → 应用市场 → 从自己的旧设备备份提取（HiSuite 备份里
那个 `com.huawei.touchshare.apk` 就是你自己的数据，来源明确）。

**修改系统设置的风险**
本仓库配套工具会读写 ADB / 系统全局设置。属于非官方途径，可能与原厂服务冲突、
导致系统行为异常，甚至影响保修。**请在充分理解风险的前提下自行决定是否使用**，
并自行承担后果。请勿用于绕过授权、商业作弊或其他不当用途。

> **能用别人的东西，是因为别人允许；不是因为它能下载到。**
> 这里只随附明确允许再分发的东西，其余一律只给获取方式。
